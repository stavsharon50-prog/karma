# KARMA.

הכול חוזר.

ביפים, גוד קארמה ומתנות אמיתיות מעסקים קטנים, בין חברים. אתר שעובד בטלפון וגם אפשר להתקין אותו על המסך הראשי.

## איפה זה עומד

**פרוטוטייפ v2, במצב הדגמה.** כל המסכים שהחלטנו עליהם עובדים, אבל:

- הנתונים נשמרים רק בטלפון שפותח את האתר.
- החברים מדומים ועונים אחרי כמה שניות.
- העסקים לדוגמה: קפה לוטוס, גלידה של שלום, פרחי השוק, מאפיית אלמה.
- התשלום מדומה: לא נגבה כסף.
- הכניסה עם Google מדומה.

השלבים הבאים: חיבור לשרת (Supabase) לפי המודל החדש, ספק סליקה עם חלוקה אוטומטית לעסק, ואחר כך אפליקציה בחנויות.

## עיקרי ההחלטות

- **בלי אנונימיות.** תמיד רואים מי שלח.
- **ביף אחד, בלי סוגים.** רק חריפות 🌶 / 🌶🌶 / 🌶🌶🌶. ביף של 🌶 מתקרר לבד אחרי שבוע.
- **סגירת חשבון:** מתנה אמיתית סוגרת מיד. מחווה בחינם (התנצלות, סטורי, שיר) צריכה אישור, ואפשר לשדרג לקפה.
- **מתנות אמיתיות בלבד, איסוף מהמקום.** בלי הבטחות.
- **מימוש:** מסך חי עם QR, והצוות מקליד את קוד העסק. מי ששלח לא מקבל הודעה כשמממשים.
- **התערבויות:** על הכבוד, קפה או גלידה. בלי הצעה נגדית. שני הצדדים מסמנים מי ניצח.
- **התראות:** ביף, גוד קארמה והתערבות חדשה מגיעים מיד. כל השאר בסיכום יומי (18:00). שקט בלילה.
- **עסקים:** צירוף ידני בפגישה, עד 3 מוצרים, עמלה 10%, חודש ראשון בלי עמלה, הכסף לעסק מרגע המכירה (אחרי 24 שעות לביטול), העברה חודשית.

## להתחיל להשתמש בהדגמה

פותחים את האתר. במסך הכניסה, בקישור הקטן למטה, אפשר לראות איך זה נראה כשמזמינים אותך עם ביף, עם גוד קארמה או בהזמנה רגילה. בפרופיל יש קישורים לצד העסק, וכפתור "איפוס ההדגמה".
