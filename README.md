# KARMA.

כל חשבון פתוח נסגר בסוף. בכיף.

גרסה ראשונה (MVP) לניסוי עם משתמשים: אתר שעובד בטלפון וגם אפשר להתקין אותו על המסך הראשי. בלי App Store, ובלי שלב build.

## מה יש בפנים

| קובץ | תפקיד |
|---|---|
| `index.html` | המעטפת של האפליקציה |
| `app.css` | העיצוב, לפי ה-Design System בפיגמה |
| `app.js` | כל המסכים והניווט |
| `api.js` | החיבור לשרת (Supabase), וגם מצב הדגמה עם חברים מדומים |
| `moderation.js` | סינון טקסט: קללות, איומים, גזענות, הערות על מראה וחרם |
| `config.js` | **הקובץ היחיד שצריך למלא**: הכתובת והמפתח של Supabase |
| `supabase/schema.sql` | בסיס הנתונים, ההרשאות וכללי הפרטיות |
| `sw.js`, `manifest.webmanifest`, `icons/` | התקנה כאפליקציה ואייקונים |

כל עוד `config.js` ריק, האפליקציה רצה **במצב הדגמה**: יש בה חברים מדומים שעונים לך אחרי כמה שניות, והנתונים נשמרים רק בטלפון.

## הפעלה (פעם אחת)

1. **Supabase:** יוצרים פרויקט, ואז בתפריט **SQL Editor** ← **New query** מדביקים את כל התוכן של `supabase/schema.sql` ולוחצים **Run**. אפשר להריץ שוב בכל עדכון, בלי לאבד נתונים.
2. **כניסה עם Google:** ב-Supabase נכנסים ל-**Authentication** ← **Providers** ← **Google** ומפעילים. צריך Client ID ו-Secret מ-Google Cloud Console.
3. **כתובות מותרות:** ב-**Authentication** ← **URL Configuration** מגדירים **Site URL** = `https://stavsharon50-prog.github.io/karma/` ומוסיפים אותה גם ל-**Redirect URLs**.
4. **config.js:** מעתיקים מ-**Project Settings** ← **API** את ה-Project URL ואת ה-anon public key. מותר לפרסם את שניהם, כי כללי ההרשאות במסד הנתונים הם מה שמגן על המידע.
5. **GitHub Pages:** ב-repository נכנסים ל-**Settings** ← **Pages**, בוחרים Branch `main` ותיקייה `/ (root)`.

## מה יש באפליקציה

- **ניווט:** סרגל תחתון (חשבונות · התערבויות · ➕ · גוד קארמה · המתנות שלי), פעמון התראות, ומסך היכרות למשתמש חדש.
- **התראות:** כל מה שקרה, עם קישור. בביף אנונימי ההתראה לא חושפת מי פתח אותו.
- **המתנות שלי:** כל מה שמגיע לך (קפה מסגירת חשבון, חובות מהתערבויות, מתנות מגוד קארמה), עם סימון "קיבלתי".
- **Karma Wrapped:** סיכום חודשי לשיתוף.
- **חשבונות:** ביפים (ביף, חוב, הבטחה, פדיחה), סגירת חשבון, הסדר עיוור, סליחה ו"שחררתי".
- **התערבויות:** זורקים כפפה לחבר, הוא מאשר או מציע מחיר אחר, כל צד מסמן מי ניצח, והמנצח מסמן כשקיבל. רק על קפה, טובות והתנצלויות.
- **גוד קארמה:** שולחים תודה, מזל טוב או "סתם כי התגעגעתי", עכשיו או בזמן מתוזמן (מחר בבוקר, ביום ההולדת, הפתעה השבוע).
- **גוד קארמה אנונימית:** נחשפת רק אם שני הצדדים מסכימים.
- **להעביר הלאה:** מי שקיבל גוד קארמה יכול להעביר אותה תוך 24 שעות, ונוצרת שרשרת.
- **קופה משותפת:** כרטיס ברכה קבוצתי שכולם כותבים בו, ונשלח ביחד. (תשלום לקופה: בקרוב.)
- **מה משמח אותי** ו**המאזן עם כל חבר**.
- **בקרוב (כפתורים שמודדים עניין):** מתנות בתשלום, תרומה בשם מישהו, KARMA. for Work.

## הגנות

- **סינון טקסט** בכל מקום שאפשר לכתוב בו: סיבה, הודעה בהצעה, שם. אותן רשימות נבדקות גם באפליקציה (כדי להציג הסבר מיד) וגם במסד הנתונים (כדי שאי אפשר יהיה לעקוף אותן). מוסיפים מילים ב-`moderation.js`.
- **עצירת חרם:** אם 4 אנשים שונים פתחו טינה על אותו אדם תוך 48 שעות, אי אפשר לפתוח עוד טינות עליו לזמן מה.
- **הגבלת קצב:** עד 8 טינות חדשות ביום לכל משתמש, ועד 3 חשבונות פתוחים לכל זוג חברים.
- **השהיה:** מי שעל שתיים מהטינות שלו דיווחו "זה לא מצחיק אותי" בתוך 30 יום, לא יכול לפתוח טינות חדשות.

## פרטיות וחשבון

- מסכי **מדיניות פרטיות** ו**תנאי שימוש** (טיוטה, לבדיקת עורך דין), עם קישור במסך הכניסה.
- **מחיקת חשבון** מהפרופיל: מוחקת את הפרופיל וכל מה שקשור אליו.

## מה נמדד

כל פעולה חשובה נרשמת בטבלה `events`: הרשמה, טינה שנוצרה, הזמנה ששותפה, הצעה שנשלחה, חשבון שנסגר, דיווח, וכמה אנשים לחצו על Karma Gifts.
